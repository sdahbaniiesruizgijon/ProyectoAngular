Stack Tecnológico NutriSport

Arquitectura Full-Stack orientada a la salud y el rendimiento deportivo

Interfaz y UX (DIW)

Desarrollo de interfaz bajo metodología Mobile-First y frameworks de última generación.

  • Framework CSS: Bootstrap 5 personalizado íntegramente mediante Sass, permitiendo la redefinición de estilos globales y variables de marca.
  • Accesibilidad (RA 6): Implementación de semántica HTML5, roles ARIA y contrastes validados para garantizar la navegación a todo tipo de usuarios.
  • Diseño Homogéneo: Uso de componentes de Angular 17+ para mantener una identidad visual coherente en todas las pantallas del aplicativo.

Backend & API Engine

Gestión de lógica de negocio y persistencia de datos segura.

  • Core System: API REST desarrollada en Laravel 10, gestionando la autenticación mediante tokens y el control de recursos.
  • Base de Datos: Almacenamiento local para la gestión de usuarios, diarios de comida y bibliotecas personalizadas de alimentos.
  • Integración Externa: Conexión en tiempo real con la API de Open Food Facts para la obtención de datos nutricionales globales.

Divulgación y Comunidad

Complementamos nuestra herramienta técnica con fuentes de información real y contenido de bienestar de calidad.
